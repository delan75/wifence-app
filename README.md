# Mobile

Flutter mobile app for NetworkApp.

Current scope:

- dashboard view
- device list
- device detail
- pause and resume
- quota editing
- category rule creation

The app currently expects the local gateway API at `http://10.0.2.2:8000` for Android emulator testing.

## Run locally

1. Start the gateway on port `8000`
2. `cd mobile`
3. `flutter pub get`
4. `flutter run`
